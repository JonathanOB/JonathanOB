### Projects


#### **HostSentinel**  
A lightweight host-based intrusion detection system for Linux VPS servers. It includes SSH and HTTP honeypots, real-time analysis of authentication logs, SHA-256 file integrity monitoring, detection of privilege changes, port monitoring and enrichment of attacker data with GeoIP and WHOIS information. The system provides a live dashboard using Server-Sent Events and supports alerting via email and Discord. It runs as a hardened systemd service with no external cloud dependencies.  
[Host Sentinel Github Repo](https://github.com/JonathanOB/HostSentinel)

#### **Spectrum Schedule**  
A visual scheduling and routine application built for neurodivergent individuals, those with ADHD, and their caregivers or support workers. It offers extensive accessibility options including multiple themes (with high-contrast and dyslexia-friendly variants), adjustable typography and motion settings, full keyboard navigation, offline support, caregiver share links, and printable schedules. This is a non-clinical project developed as a test for creating applications that provide WCAG 2.2, W3C COGA, Microsoft Inclusive Design, BBC Accessibility Guidelines, and Dyslexia-Friendly Fonts.   
[Spectrum Schedule Github Repo](https://github.com/JonathanOB/SpectrumSchedule)

**Architecture AI**  
A web application that converts 2D hand-drawn floor plan sketches into photorealistic architectural renders using Google Gemini. It preserves geometric details from the original sketch and includes an interactive comparison view, PNG export, and secure project storage through Puter. The application handles user authentication, data persistence, and sharing while keeping validation and storage isolated per user.  
[Architecture AI Github Repo](https://github.com/JonathanOB/ArchitectureAI)
